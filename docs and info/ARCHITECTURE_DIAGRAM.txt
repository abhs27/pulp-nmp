================================================================================
  HASH GENERATION FLOW (Compiler/Software Side)
================================================================================

  Input Addresses:
  ┌──────────────────────────────────────────┐
  │  rs1_base = 0x10000000 (32 bits)         │
  │  rs2_base = 0x20000000 (32 bits)         │
  │  rd_base  = 0x30000000 (32 bits)         │
  └──────────────────┬───────────────────────┘
                     │
                     ▼
       ╔═════════════════════════════╗
       ║  Step 1: XOR Combine        ║
       ║                             ║
       ║  combined =                 ║
       ║    0x10000000 ⊕             ║
       ║    0x20000000 ⊕             ║
       ║    0x30000000               ║
       ║  = 0x00000000               ║
       ╚══════════════╤══════════════╝
                      │
                      ▼
       ╔═════════════════════════════╗
       ║  Step 2: Multiply           ║
       ║                             ║
       ║  mixed =                    ║
       ║    combined ×               ║
       ║    0x9E3779B9               ║
       ║    (Golden Ratio)           ║
       ║  = 0x00000000               ║
       ╚══════════════╤══════════════╝
                      │
                      ▼
       ╔═════════════════════════════╗
       ║  Step 3: Extract Bits       ║
       ║                             ║
       ║  hash =                     ║
       ║    mixed[31:15]             ║
       ║  = 0x00000 (17 bits)        ║
       ╚══════════════╤══════════════╝
                      │
                      ▼
              ┌───────────────┐
              │  hash_17bit   │
              │   (0-131071)  │
              └───────┬───────┘
                      │
        ┌─────────────┴─────────────┐
        │                           │
        ▼                           ▼
  Store in ALT          Embed in Instruction
  (initialization)      [31:15] = hash
