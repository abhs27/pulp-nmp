1. opcode [6:0] = 7 bits ✓ USED
   Value: 1101011 (0x6b)
   Purpose: Identifies instruction as NMP operation
   Status: LOCKED (must be 0x6b for NMP)

2. funct3 [14:12] = 3 bits ✓ USED
   Current: 000 (NMP_ADD)
   Purpose: Selects which NMP operation
   Available values:
     000 = NMP_ADD ← Currently implemented
     001 = NMP_SUB ← Available for future
     010 = NMP_MUL ← Available for future
     011 = NMP_DIV ← Available for future
     100 = NMP_AND ← Available for future
     101 = NMP_OR  ← Available for future
     110 = NMP_XOR ← Available for future
     111 = Reserved ← Available for future
   
   Note: 7 out of 8 values still available!

3. rs2 [24:20] = 5 bits ✓ USED
   Value: size (0-31)
   Purpose: Array size / element count
   Status: FULLY USED for array size
   Range: Can specify 0 to 31 elements

ENCODING CAPACITY
═══════════════════════════════════════════════════════════════════════════

With current encoding, you can support:

1. Operations (via funct3): 8 different operations
   - Currently using: 1 (ADD)
   - Available: 7 more operations

2. Extended Variants (via funct7): 128 variants per operation
   - Total possible instructions: 8 × 128 = 1,024 different NMP instructions!

3. Configuration Space (via rs1 + rd): 32 × 32 = 1,024 configurations
   - Can specify source/destination registers
   - Can add flags, modes, data types, etc.

4. Array Sizes (via rs2): 32 different sizes (0-31 elements)
   - Currently fully utilized

RECOMMENDED USAGE STRATEGY
═══════════════════════════════════════════════════════════════════════════

Phase 1 (Current): Basic Operations
  - Use funct3 for: ADD, SUB, MUL, DIV, AND, OR, XOR
  - Keep rs1, rd, funct7 as zeros
  - Focus on getting basic array operations working

Phase 2: Data Types & Modes
  - Use rs1[2:0] for data type selection:
    000 = int32 (default)
    001 = int16
    010 = int8
    011 = float32
    etc.
  - Use rd[0] for saturation mode (0=wrap, 1=saturate)
  - Use funct7[0] for signed/unsigned mode

Phase 3: Advanced Features
  - Use rs1[4:3] for memory stride
  - Use rd[4:1] for destination register
  - Use funct7[6:1] for extended configurations

Phase 4: Custom Operations
  - Use funct3=111 for custom/extended operations
  - Use funct7 to specify custom operation type

COMPARISON: OLD vs NEW
═══════════════════════════════════════════════════════════════════════════

OLD Encoding (0x33 opcode):
  FREE: 10 bits (rs1=5, rd=5)
  USED: 22 bits (opcode=7, funct3=3, funct7=7, rs2=5)
  Limitation: funct7 consumed for NMP identification

NEW Encoding (0x6b opcode):
  FREE: 17 bits (rs1=5, rd=5, funct7=7)
  USED: 15 bits (opcode=7, funct3=3, rs2=5)
  Advantage: funct7 now available for extensions!

Improvement: 70% MORE free encoding space! (17 vs 10 bits)
