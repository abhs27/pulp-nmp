BENEFITS ACHIEVED
═══════════════════════════════════════════════════════════════════════════

✅ Cleaner Architecture
   - No longer conflicting with standard R-type instructions
   - Uses PULPino's designated custom opcode space

✅ Simplified Decoding
   - Only need to check opcode (0x6b) + funct3
   - Removed funct7 check requirement
   - Fewer logic gates, faster decode

✅ Increased Extensibility
   - 8 operations possible via funct3 (currently using 1)
   - 17 bits now available for future features:
     * funct7 [31:25] = 7 bits for extended config
     * rs1 [19:15]    = 5 bits for flags/options
     * rd [11:7]      = 5 bits for destination/config

✅ Standards Compliant
   - Follows RISC-V custom instruction guidelines
   - Aligns with PULPino architecture
   - Uses already-defined OPCODE_NMP_OP constant
